# 🏙️ Civic Issue Reporter

A modern full-stack platform that enables citizens to report civic and infrastructure issues while helping authorities track, manage, and resolve them efficiently.

Built with a focus on real-world governance workflows, secure authentication, geolocation support, image uploads, and transparent issue tracking.

---

## 🚀 Project Overview

Civic Issue Reporter bridges the gap between citizens and local authorities by providing a centralized platform for reporting public issues such as:

* Road damage and potholes
* Garbage collection problems
* Water supply issues
* Streetlight failures
* Drainage and sanitation concerns
* Public infrastructure complaints

The platform streamlines issue reporting, monitoring, and resolution through role-based dashboards for both citizens and administrators.

## ✨ Key Features

### 👤 Citizen Portal

* Secure registration and authentication
* Report civic issues with detailed descriptions
* Upload supporting images
* Specify location information
* Track issue progress in real time
* View personal issue history
* Delete self-submitted reports

### 🛡️ Admin Dashboard

* View all reported issues
* Monitor platform activity
* Update issue status:

  * Reported
  * In Progress
  * Resolved
* Delete invalid or duplicate reports
* Manage issue workflows efficiently

### 🌍 Platform Features

* JWT-based authentication
* Cloud image storage
* Responsive modern UI
* Form validation using Zod
* Protected API routes
* Scalable MongoDB database design
* Modular component architecture
